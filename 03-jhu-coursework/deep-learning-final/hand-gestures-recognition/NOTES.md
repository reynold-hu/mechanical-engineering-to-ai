# 原理讲解：手势识别（MediaPipe + 自建数据集）

> 这个作业教**「怎么在数据不够时，用先验知识补上」**。
> 我们没有 8000 张图就训 CNN，而是先把手「抽象成 21 个点」。

---

## 一、核心思路：先降维，再分类

**直接上 CNN 的问题：** 要识别手势，至少需要几万张标注图像，还要考虑
背景、光照、肤色、手的大小……**标注成本极高**。

**我们的做法：**

```
摄像头图像
   ↓  MediaPipe Hands（现成的关键点检测器）
21 个关键点 × (x, y) = 42 个数
   ↓  训练一个很小的分类器
手势类别
```

**关键洞察：手部关键点把「识别手势」这个问题，从图像空间搬到了
一个 42 维的、干净的、与背景无关的空间。**

**好处：**
- **数据量骤降** —— 几百到几千个样本就够
- **对背景/光照免疫** —— 关键点已经是抽象后的坐标
- **训练极快** —— 分类器只有几层全连接

**代价：** 依赖 MediaPipe 的质量。手被遮挡、光线太差时，关键点会飘。

---

## 二、两套分类器

作业里做了两个，看**不同的信息**：

| 分类器 | 输入 | 识别什么 |
|:---|:---|:---|
| **keypoint_classifier** | 当前帧的 21 个关键点 | **静态手势**（手的形状） |
| **point_history_classifier** | 若干帧关键点的**变化** | **动态手势**（手的运动轨迹） |

**静态 vs 动态**的区别很关键：
- 比「OK」手势 —— 手不动，看形状就够
- 比「招手」—— 手在动，**必须看时间序列**

`point_history` 把最近几帧的关键点拼成一个向量，这样就能捕捉运动模式。

## 三、数据是怎么来的（本项目的特色）

**这批数据是我们自己用摄像头采集的** —— 8000+ 样本、8 种手势。

采集脚本（`Get Train Dataset.py` / `Get Test Dataset.py`）每一帧做两件事：

```python
# ① 存 21 个关键点坐标（42 个数）
np.savetxt(lmhandle, flatten, delimiter=',')

# ② 抠出手部包围盒 → 缩放到 28×28 → 展平成 2352 个数
cropped = framergb[brect[1]:brect[3], brect[0]:brect[2], :]
reshaped = np.uint8(reshape(cropped, 28))
np.savetxt(imghandle, img_flatten, delimiter=',')
```

**为什么两套都存？** 关键点给分类器用，**像素图可以作为对照实验**
（看看"直接喂图"和"喂关键点"差多少）。

## 四、关键的工程细节

### reshape：为什么要把手缩放到 28×28

```python
def reshape(a, l):
    # 把任意大小的手部区域，平均池化成 l×l
    for k in range(3):
        for i in range(l):
            for j in range(l):
                newimage[i,j,k] = np.average(a[i*h:(i+1)*h, j*w:(j+1)*w, k])
```

**目的：归一化尺度。** 手离镜头远近不同，抠出来的框大小不同。
统一缩到 28×28，让"手大"和"手小"在数据上看起来一样。

**这是数据预处理里最典型的操作 —— 消除与任务无关的变化。**

### 边界框留 margin

```python
return [max(0,x-20), max(0,y-20), min(x+w+20, image_width-1), min(y+h+20, image_height-1)]
```

`±20` 是给框留边距。**不留的话会切掉指尖和手腕的关键信息**。

## 五、这个思路的通用性

**「先用现成模型提取中间表示，再训练小模型」** —— 这是非常通用的范式：

| 领域 | 现成提取器 | 下游小模型 |
|:---|:---|:---|
| 手部（本项目） | MediaPipe Hands | 全连接分类器 |
| 人体 | MediaPipe Pose | 动作识别 |
| 人脸 | 人脸检测 + 对齐 | 表情/年龄识别 |
| 文本 | BERT 编码器 | 分类/情感分析 |
| 图像 | CLIP / ResNet 特征 | 少样本分类 |

> 💡 **在数据稀缺时，"用先验知识降维"往往比"堆数据"更有效。**

**建议的改进方向：**

- **时序模型** —— 把 point_history 那套换成 LSTM/GRU，动态手势会更准
- **双手支持** —— 现在 `max_num_hands=1`，改成 2 试试
- **对比实验** —— 直接喂 28×28 图像训 CNN，看哪个准确率高
