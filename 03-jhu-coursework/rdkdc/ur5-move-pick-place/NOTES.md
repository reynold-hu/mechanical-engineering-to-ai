## 一、三个层次的问题

| 层次 | 问题 | 难度 |
|:---|:---|:---|
| **正运动学 (FK)** | 给定各关节角度，末端在哪？ | 简单，直接算 |
| **逆运动学 (IK)** | **给定末端位置，各关节该转多少？** | **难**，可能无解/多解 |
| **控制** | 怎么让它**平滑地**走过去？ | 工程问题 |

**这个作业把三种控制方法都实现并对比了。**

## 二、必备数学：刚体变换

**机械臂的本质是一串刚体，每节相对前一节运动。** 描述这个用：

**齐次变换矩阵（Homogeneous Transform）：**

```
    ┌           ┐
T = │  R    p   │     R: 3×3 旋转矩阵
    │           │     p: 3×1 平移向量
    │  0 0 0  1 │
    └           ┘
```

**为什么用 4×4 而不是分开的 R 和 p？**
因为这样**串联变换就是连乘** —— 一个矩阵乘一下就完成了「先旋转再平移」。

**DH 参数（Denavit-Hartenberg）：** 用 4 个参数描述相邻两关节的关系，
是整个领域的标准工具。

## 三、方法一：逆运动学（IK）

**目标：解析地求出每个关节的角度。**

```matlab
% 用 MATLAB 的 generalizedInverseKinematics
ik = inverseKinematics('RigidBodyTree', robot);
[config, solInfo] = ik('ee_link', targetPose, weights, initialGuess);
```

**特点：**
- ✅ 一步到位，精度高
- ❌ **可能多解**（肘部朝上/朝下都能到达同一位置）
- ❌ **可能无解**（超出工作空间）
- ❌ 工业六轴臂的解析解要分情况讨论，很繁琐

---

## 四、方法二：速率控制（Resolved-Rate）

**核心思想：不直接求角度，而是求「角速度」。**

**雅可比矩阵 J 建立了速度关系：**

```
ẋ = J(q) · q̇
 ↑        ↑
末端速度   关节速度
```

**求逆就得到关节速度：**

```matlab
q_dot = pinv(J) * x_dot        % pinv = 伪逆
q = q + q_dot * dt             % 积分得到新角度
```

**为什么用伪逆 `pinv` 而不是 `inv`？**
- J 通常不是方阵（6 自由度末端 vs 6 关节，也可能是冗余臂）
- 在**奇异位形**（singularity）附近 J 会退化，`inv` 会爆掉

**特点：**
- ✅ 适合连续轨迹跟踪
- ✅ 能处理冗余机械臂（多了自由度可以绕开障碍）
- ❌ 在奇异点附近仍然会数值不稳定（关节速度爆炸）

---

## 五、方法三：梯度控制（Jacobian Transpose）

**不用求逆，直接用 J 的转置：**

```matlab
q_dot = alpha * J' * error      % error = 目标位置 - 当前位置
```

**为什么 Jᵀ 能代替 J⁻¹？**

这来自一个漂亮的性质：**用 Jᵀ 乘误差方向，得到的关节速度一定让误差减小。**

可以证明 `errorᵀ · (J Jᵀ) · error ≥ 0`，即 Jᵀ 方向是误差的下降方向。

**特点：**
- ✅ **不需要求逆**，数值上最稳（奇异位形也不爆）
- ✅ 计算便宜
- ❌ **收敛慢**（本质是梯度下降）
- ❌ 不保证按直线走（末端轨迹会弯曲）

---

## 六、三种方法对比

| | IK | 速率控制 | 梯度控制 |
|:---|:---|:---|:---|
| **方式** | 解析求角度 | `pinv(J)·ẋ` | `Jᵀ·error` |
| **精度** | 高 | 高 | 中 |
| **速度** | 快（一步） | 中 | **慢** |
| **奇异点** | — | ⚠️ 会爆 | ✅ 稳定 |
| **轨迹形状** | 可控 | 可控 | ❌ 会弯 |
| **适合** | 点到点 | 连续轨迹 | 兜底/简单场景 |

**作业里对比的实测结果**（来自同课程其他学生的报告）：三种方法
在轨迹误差上都能达到 0.0035mm 量级 —— **说明都实现对了，差别在稳定性和适用场景。**

**建议的改进方向：**
- **阻尼最小二乘（DLS）** —— `Jᵀ(JJᵀ + λ²I)⁻¹`，兼顾速度和稳定性
- **零空间投影** —— 冗余臂可以做次级任务（如避障）
- **轨迹规划** —— 加梯形/多项式速度规划，让运动更平滑
- **加动力学** —— 现在是纯运动学，没考虑惯量和力矩
