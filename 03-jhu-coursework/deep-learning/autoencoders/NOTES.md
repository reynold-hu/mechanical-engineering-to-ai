# 原理讲解：自编码器

> 这个作业教**「让网络自己学会压缩」**。
> 它没有标签 —— 输入就是监督信号，这叫**自监督学习**。

---

## 一、核心结构：一个瓶颈

```
   输入 x ──▶ [编码器] ──▶ 隐层 z ──▶ [解码器] ──▶ 输出 x̂
   784维                   低维                  784维
                            ↑
                        「瓶颈」Bottleneck
```

**目标：让 `x̂` 尽可能接近 `x`。**

看起来像废话（复制输入？），**关键在于中间的 `z` 维度远小于输入** ——
网络被迫学会「**用更少的数字概括输入**」。

这就是**降维**：把 784 维压缩成比如 32 维，还能还原回来。

---

## 二、为什么这有用

**核心思想：数据虽然高维，但真的「自由度」低。**

784 维空间里，手写数字只占据一个很小的、低维的流形（manifold）。
自编码器就是在**学这个流形**。

**三个关键：**
1. **压缩** —— 找到数据的本质特征
2. **无监督** —— 不需要人工标注
3. **可迁移** —— 学到的 `z` 可以用作下游任务的特征

---

## 三、作业里的两个任务

### 任务 1 · 图像重建

```python
class Autoencoder(nn.Module):
    def __init__(self):
        self.encoder = nn.Sequential(
            nn.Linear(784, 256), nn.ReLU(),
            nn.Linear(256, 64),  nn.ReLU(),     # ← 瓶颈
        )
        self.decoder = nn.Sequential(
            nn.Linear(64, 256),  nn.ReLU(),
            nn.Linear(256, 784), nn.Sigmoid(),  # ← 还原到 [0,1]
        )

    def forward(self, x):
        return self.decoder(self.encoder(x))
```

**损失函数：**
```python
loss = nn.MSELoss()(output, input)     # 重建误差
```

> 注意：**输入和目标是同一个东西**。这就是「自监督」。

### 任务 2 · 去噪

**做法：输入加噪图，目标是干净的图。**

```python
noisy = clean + noise_factor * torch.randn_like(clean)
output = model(noisy)          # 输入噪声
loss = MSELoss()(output, clean)  # 目标是干净图  ← 关键差别
```

**为什么这更强：**
- 重建任务可能只是「学了个恒等映射」
- 去噪**强制网络理解「什么才是真实的手写数字」** ——
  它必须知道「噪声长什么样」才能去掉

**这直接导向了今天的扩散模型（Diffusion Models）** ——
它们本质上是「学了去噪的自编码器」。

## 四、变体：从 AE 到 VAE

**普通自编码器的问题：`z` 空间是「破碎」的。**

你随便在 `z` 空间取一个点解码，得到的可能是垃圾 —— 因为训练时只见过
真实数据对应的那些点。

**VAE（变分自编码器）的解决：让 `z` 服从分布（通常是高斯）。**

```
编码器输出两个向量：均值 μ 和方差 σ
从 N(μ, σ²) 采样得到 z
```

**好处：`z` 空间连续且平滑，可以插值。**
在两个人脸之间插值，能得到「中间的脸」—— 这就是生成模型的起点。

---

## 五、自编码器 vs 其他降维方法

| 方法 | 类型 | 特点 |
|:---|:---|:---|
| **PCA** | 线性 | 闭式解，快，但只能学线性 |
| **自编码器** | 非线性 | 需要训练，但能学复杂流形 |
| **t-SNE / UMAP** | 非线性 | 主要做可视化，不擅长重建 |

**关系：如果去掉所有非线性激活，自编码器就退化成 PCA。**

**建议的改进方向：**
- **卷积自编码器** —— 用 Conv2d 替代 Linear，保留空间结构，重建质量会好很多
- **去噪强度调参** —— `noise_factor` 太大模型学不动，太小等于没去噪
- **稀疏自编码器** —— 加 L1 惩罚让 z 变稀疏
- **VAE** —— 让 z 服从高斯，获得生成能力
