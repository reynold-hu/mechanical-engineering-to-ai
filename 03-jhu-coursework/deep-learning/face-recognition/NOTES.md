## 二、k-NN：最朴素的分类器

**规则只有一句：**

> 找训练集里**离它最近的 k 个样本**，看它们多数是什么类别。

```python
from sklearn.neighbors import KNeighborsClassifier
knn = KNeighborsClassifier(n_neighbors=5)
knn.fit(X_train, y_train)
y_pred = knn.predict(X_test)
```

**没有任何「训练」过程** —— 它只是把训练数据存起来。这叫 **懒惰学习（Lazy Learning）**。

**优缺点：**

| ✅ | ❌ |
|---|---|
| 简单，无需训练 | 预测时要遍历全部训练数据（慢） |
| 天然支持多分类 | **维度灾难** —— 1024 维时「近邻」概念失效 |
| 非线性决策边界 | 对不相关特征和尺度敏感 |

---

## 三、维度灾难：k-NN 的致命问题

**1024 维空间里，所有点之间的距离都差不多远。**

这个直觉很难接受，但可以这么想：
- 1 维线段上，你可以说「A 在 B 左边」
- 1024 维超立方体里，**几乎所有的体积都在「角落」附近**，
  中心区域几乎是空的

**后果：** 「最近邻」不再有意义 —— 最近的邻居可能和随机点一样远。

**这就是为什么人脸识别必须**先降维**。

---

## 四、降维方法

作业里对比了几种：

### PCA（主成分分析）

**找数据方差最大的方向，投影过去。**

```python
from sklearn.decomposition import PCA
pca = PCA(n_components=50)
X_reduced = pca.fit_transform(X)     # 1024 维 → 50 维
```

**思想**：方差大 = 信息多。把 1024 维里「没用」的方向丢掉。

**在人脸上的特殊名字：Eigenfaces（特征脸）** ——
把 PCA 的主成分**还原成图像**，会发现它们像一张张"幽灵脸"。

### LDA（线性判别分析）

**PCA 不管类别，LDA 利用标签。**

> PCA 找「**数据**方差最大」的方向
> LDA 找「**类间**方差大、**类内**方差小」的方向

**人脸版本叫 Fisherfaces。**

**区别：** PCA 是无监督的，可能丢掉对分类最有用、但总方差小的方向。

## 五、经典人脸识别的完整流程

```
原始图像
   ↓  预处理（对齐、裁剪、光照归一化）
   ↓  降维（PCA / LDA）
   ↓  特征表示
   ↓  分类（k-NN / SVM / 最近邻）
识别结果
```

**每一步都重要** —— 尤其**光照归一化**，因为 Yale B 数据集专门考这个。

---

## 六、为什么深度学习赢了

**经典方法的瓶颈：**

| 问题 | 经典方法 | 深度学习 |
|:---|:---|:---|
| 特征 | **人工设计**（PCA/LDA） | **端到端学出来** |
| 光照/姿态 | 需要专门归一化 | 数据够多就能学到不变性 |
| 尺度 | 高维就崩溃 | 百万维也照跑 |

**关键转变：** 从「**人设计特征**」到「**网络自己学特征**」。
深度学习后的主流是 **度量学习**（FaceNet 的 triplet loss）——
不再做分类，而是学一个「同一个人的脸距离近」的嵌入空间。
