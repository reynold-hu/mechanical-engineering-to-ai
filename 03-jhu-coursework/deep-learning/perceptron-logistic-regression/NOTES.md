# 原理讲解：从感知机到逻辑回归

> **这个作业最有价值的地方：不许用 `torch.nn`，所有东西从零手写。**
> 你会被迫真正理解「梯度下降到底在算什么」。

---

## 一、问题：手写数字二分类

MNIST 是 28×28 的灰度图，展平成 **784 维向量**。

作业要求：把「10 分类」拆成 **10 个二分类问题** ——

> 对每个数字 k∈{0..9}，训练一个分类器判断「**这张图是 k 还是不是 k**」
> （即 k / 非 k 的 2-way 分类）

---

## 二、感知机：最简单的线性分类器

**模型：**

```
z = w·x + b          # 线性加权
ŷ = step(z)          # 阶跃函数：z>0 输出 1，否则 0
```

**学习规则**（1958 年 Rosenblatt 提出）：

```python
for x, y in data:
    ŷ = predict(x)
    if ŷ != y:
        w += lr * (y - ŷ) * x    # 只在分错时更新
        b += lr * (y - ŷ)
```

**致命缺陷：** 阶跃函数**不可导** —— 梯度处处为 0（除原点）。
所以没法用梯度下降，而且**只能解决线性可分问题**（异或都做不了）。

---

## 三、逻辑回归：换成可导的

**关键改动：把阶跃换成 Sigmoid。**

```
z = w·x + b
ŷ = σ(z) = 1 / (1 + e^(-z))         # 输出 (0,1) 之间的概率
```

```python
def sigmoid(z):
    return 1 / (1 + np.exp(-z))
```

**Sigmoid 的好处：**
1. 输出是**概率**，可解释
2. **处处可导**，能用梯度下降
3. 导数形式漂亮：`σ'(z) = σ(z)·(1-σ(z))`

---

## 四、损失函数：交叉熵

**不要用均方误差（MSE）** —— 配合 Sigmoid 会让梯度消失。

**用交叉熵（Cross-Entropy）：**

```
L = -[ y·log(ŷ) + (1-y)·log(1-ŷ) ]
```

**直觉：**
- 真实标签 y=1，模型预测 ŷ=0.9 → 损失小
- 真实标签 y=1，模型预测 ŷ=0.1 → 损失**很大**

它惩罚「自信地答错」。

---

## 五、梯度推导：这个作业的核心

**交叉熵 + Sigmoid 的梯度会化简成一个极简形式：**

```
∂L/∂z = ŷ - y
```

**证明思路（链式法则）：**

```
∂L/∂z = ∂L/∂ŷ · ∂ŷ/∂z
      = (ŷ-y)/(ŷ(1-ŷ)) · ŷ(1-ŷ)      ← 两项正好约掉
      = ŷ - y
```

**这个「预测值减真实值」的形式，是深度学习里最常见的结果** ——
从逻辑回归到 Transformer，输出层的梯度几乎都是这个形状。

**参数梯度：**

```python
dz = y_hat - y                 # (N,)
dw = X.T @ dz / N              # (784,)
db = np.mean(dz)               # scalar
```

---

## 六、训练循环

```python
for epoch in range(n_epochs):
    # 前向
    z     = X @ w + b
    y_hat = sigmoid(z)

    # 损失
    loss = -np.mean(y*np.log(y_hat+1e-9) + (1-y)*np.log(1-y_hat+1e-9))

    # 反向
    dz = (y_hat - y) / N
    dw = X.T @ dz
    db = np.sum(dz)

    # 更新
    w -= lr * dw
    b -= lr * db
```

> 💡 **`+1e-9` 是防 `log(0)`** —— 这个细节很常见，面试也爱问。

---

## 七、从逻辑回归到神经网络

**这个作业是理解深度学习的门户**，因为：

| 逻辑回归 | 神经网络 |
|:---|:---|
| 一层 `σ(Wx+b)` | 多层 `σ(W₂σ(W₁x+b₁)+b₂)` |
| 手推梯度 | **反向传播**（就是链式法则） |
| 二分类 | 多分类（Softmax） |

**本质完全一样** —— 都是「前向算输出 → 算损失 → 反向求梯度 → 更新参数」。
区别只是**层数变多，链式法则变长**。

**读懂这个作业的梯度推导，再去看反向传播，会发现是同一件事。**

**建议的改进方向：**
- **Softmax 多分类** —— 一次搞定 10 类，而不是训练 10 个二分类器
- **加隐藏层** —— 就变成真正的神经网络了
- **Mini-batch** —— 现在用的是全量梯度下降，改成小批量会快很多
- **正则化** —— 加 L2 惩罚，防过拟合
