# 原理讲解：迁移学习与微调

> 这个作业教**「怎么站在别人的肩膀上」** —— 也是实际工作里最常用的 DL 技能。
> 从零训练一个 CNN 要几百万张图；微调只要几千张。

---

## 一、核心思想：预训练 + 微调

**观察：** 在 ImageNet（1400 万张图、1000 类）上训练的 CNN，
它的**浅层学到的东西是通用的**：

| 层 | 学到的 | 通用性 |
|:---|:---|:---|
| 浅层 | 边缘、颜色块、纹理 | 🟢 **几乎所有视觉任务都需要** |
| 中层 | 局部形状、部件 | 🟡 较通用 |
| 深层 | 物体、语义 | 🔴 和具体任务强相关 |

**所以：拿预训练模型，只改最后几层，用少量数据微调。**

---

## 二、作业里的两个模型

### AlexNet（2012）

**让深度学习爆发的那篇论文。** 结构：

```
Conv → MaxPool → Conv → MaxPool → Conv×3 → MaxPool
   → FC(4096) → FC(4096) → FC(1000)
```

**历史意义：** 2012 年 ImageNet 冠军，top-5 错误率从 26% 降到 15%。
它证明了「**GPU + 大数据 + 深网络**」这条路是对的。

### VGG-16（2014）

**AlexNet 的「更深更规整」版。**

**核心贡献：用 3×3 小卷积堆叠替代大卷积。**

为什么更好？

```
两个 3×3 卷积的感受野 = 一个 5×5
三个 3×3 的感受野     = 一个 7×7
```

**但参数量更少：**

| 方案 | 参数量 |
|:---|:---|
| 一个 7×7（64通道） | 7×7×64×64 = **200,704** |
| 三个 3×3 | 3×(3×3×64×64) = **110,592** |

**参数少一半，还多了两次非线性激活（ReLU）→ 表达能力更强。**

## 三、微调的两种方式

### 方式 A · 特征提取（Feature Extraction）

**冻结全部卷积层，只训练最后的全连接层。**

```python
model = torchvision.models.vgg16(pretrained=True)
for param in model.features.parameters():
    param.requires_grad = False        # ← 冻结
model.classifier[6] = nn.Linear(4096, n_classes)   # 换掉最后一层
```

**适用：** 数据很少（几百张）、和目标域接近。

### 方式 B · 完整微调（Fine-tuning）

**解冻部分或全部层，用很小的学习率继续训练。**

```python
for param in model.features[-4:].parameters():     # 解冻最后几层
    param.requires_grad = True
optimizer = Adam(model.parameters(), lr=1e-4)      # ← 学习率调小
```

**适用：** 数据较多、和目标域差异大。

> ⚠️ **学习率一定要调小**（1e-4 或更小）。用从零训练的学习率会
> **破坏预训练学到的权重** —— 这叫「灾难性遗忘」。

## 四、作业里的数据集：LFW

**Labeled Faces in the Wild** —— 真实场景的人脸：

- 从网络上抓取的名人照片
- **姿态、光照、表情、遮挡都很多变**（"in the wild"）
- 比实验室数据集难得多

**这正好检验「预训练特征到底有多通用」。**

---

## 五、关键概念：为什么微调有效

**假设：** 视觉任务的**底层特征是可复用的**。

无论你识别猫狗、人脸、还是医学影像，浅层都是「找边缘和纹理」。
**没必要每次从零学。**

**这背后的直觉和「人类迁移」一样：** 会骑自行车的人学摩托车很快 ——
平衡感、协调性是通用的。

## 六、到今天的演进

| 年代 | 方法 | 特点 |
|:---|:---|:---|
| 2012 | AlexNet | 从零训练（GPU 革命） |
| 2014 | VGG / GoogLeNet | 更深的架构 |
| 2015 | ResNet | 残差连接，能训 100+ 层 |
| 2018 | **BERT / GPT** | **预训练 + 微调**范式统治 NLP |
| 2020 | CLIP / ViT | 多模态，视觉也用 Transformer |
| 2023+ | **LoRA / PEFT** | 只训练**极小**一部分参数 |

> 💡 **LoRA 是大模型时代微调的主流** —— 冻结全部权重，只插入并训练
> 低秩矩阵。参数量降到 0.1%，效果却接近全量微调。
> **这个作业学的「冻结+替换」思路，就是 LoRA 的思想源头。**

**建议的改进方向：**

- **分层学习率** —— 浅层用小学习率，深层用大学习率
- **换 ResNet** —— 比 VGG 更深更准
- **LoRA** —— 试试只训练低秩矩阵

> 📚 **深入方向**：ResNet、EfficientNet、LoRA/PEFT、CLIP、自监督预训练
