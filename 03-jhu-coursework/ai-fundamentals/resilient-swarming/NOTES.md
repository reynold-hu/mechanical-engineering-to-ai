# 原理讲解：Boids 集群行为

> 这个作业在教**「简单规则怎么涌现出复杂行为」** —— 也是「多智能体系统」的起点。
> 你只给每个个体三条规则，最后却看到一群鸟一样的东西。

---

## 一、现象：鸟群为什么不会撞在一起？

1986 年，Craig Reynolds 观察鸟群后提出一个问题：

> **每只鸟并不认识整个群体，也没有「总指挥」。**
> 它只能看到附近的几只鸟。那为什么整个群体能协调一致？

他的答案就是 **Boids**（"bird-oid" = 像鸟的东西）—— **三条局部规则**：

## 二、三条规则

每个个体每一帧，只看**视野半径内的邻居**，然后：

| 规则 | 做什么 | 直觉 |
|:---|:---|:---|
| **Separation**（分离） | 远离过近的邻居 | **别撞上** |
| **Alignment**（对齐） | 朝邻居的平均朝向转 | **跟大家保持一致** |
| **Cohesion**（聚合） | 朝邻居的平均位置靠 | **别掉队** |

```python
def update(boid, neighbors):
    sep = steer_away(neighbors)      # 排斥：距离太近时推开
    ali = match_heading(neighbors)   # 对齐：转向邻居的平均朝向
    coh = steer_towards(neighbors)   # 聚合：转向邻居的质心

    accel = w_sep * sep + w_ali * ali + w_coh * coh
    boid.velocity += accel
    boid.position += boid.velocity
```

**三个权重 `w_sep / w_ali / w_coh` 是调参的关键**：

- 分离权重太大 → 群体散开
- 聚合权重太大 → 挤成一团、互相穿模
- 对齐权重太大 → 整体僵化成一条线

## 三、关键思想：涌现（Emergence）

**这是整个作业最有价值的一课：**

> **没有任何一个个体育知道「群体在往哪飞」，
> 但群体整体表现出了方向性、避障能力、以及对扰动的恢复力。**

这种「局部规则 → 全局行为」的现象叫**涌现**。

类似的例子：
- 蚁群找到最短路径（每只蚂蚁只留信息素）
- 鸟群/鱼群的集体转向
- 神经网络的能力（每个神经元很简单）

## 四、为什么叫 "Resilient"（弹性）

作业标题是 **AI Mini Project for Resilient Swarming** —— 重点是**弹性**：

**弹性的定义：** 系统在**部分失效或受扰动后**，仍能维持功能。

对集群来说：
- **打掉几只个体** → 整体队形能恢复
- **加入障碍物** → 群体能绕开而不散
- **噪声干扰** → 不崩溃

**这正是多机器人系统最关心的性质** —— 因为现实里机器人一定会出故障。

## 五、这个项目在 JHU 的语境

用的是 **Robotarium** —— Georgia Tech 的**多机器人实验平台**：

- 一个可以放几十台真实小机器人的大桌面
- 提供 MATLAB / Python API 和仿真器
- 你在仿真里写好的集群算法，可以直接推到真机上跑

作业的结构（从目录能看出来）：

```
examples/AI/          课堂示例（bounce_off_wall、estimate、check_blind_spot…）
patch_generation/     障碍物的补丁生成
utilities/            工具函数
ARobotarium.m         扩展的 Robotarium 接口
```

**注意 `estimate.m`** —— 里面有**状态估计**：每个机器人不能直接知道自己的绝对位置，
只能通过传感器估计。这是从「理想仿真」迈向「真实系统」的关键一步。

## 六、从 Boids 到今天的机器人集群

| 概念 | 在 Boids 里 | 在真实系统里 |
|:---|:---|:---|
| 个体 | 一只鸟 | 一台机器人 / 无人机 |
| 感知 | 视野半径内邻居 | 传感器 + 通信 |
| 规则 | 三条局部规则 | 更复杂的控制律 |
| 弹性 | 群体恢复队形 | 故障容错、通信中断容错 |

**现代应用：** 无人机表演、仓储机器人调度、卫星编队、集群探测。

## 七、自己动手

```matlab
% 1. 跑仿真骨架
simulation_skeleton.m

% 2. 调三个权重，观察行为变化
w_sep = 1.5;  w_ali = 1.0;  w_coh = 1.0;   % 试试各种组合

% 3. 加障碍物，看群体能不能绕开
% 4. 随机"杀死"一些个体，看弹性
```

**建议的改进方向：**
- **加障碍物避让** —— 在三条规则之外加一条「远离障碍」
- **有限通信** —— 只让部分个体知道目标位置（信息传播）
- **领导-跟随** —— 引入少数"领导者"，测试群体跟随能力
- **加噪声** —— 给感知和运动加噪声，逼近真实系统
