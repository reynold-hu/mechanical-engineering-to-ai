## 一、问题定义

**数据：** Capital Bikeshare（华盛顿共享单车）的 2019 年 12 月行程记录

**要预测什么？** 行程时长 `Duration`

**要回答什么？** 哪些因素影响骑行时长？（周次、日期、季节、会员类型…）

> ⚠️ 注意这是 **回归问题**（预测连续值），不是分类。

---

## 二、真实数据有多脏

原始数据字段（CSV）：

| 字段 | 类型 | 问题 |
|:---|:---|:---|
| `Duration` | 数值 | **离群值** —— 有人骑了 24 小时没还车 |
| `Start date` / `End date` | 字符串 | 要解析成时间，还要算特征 |
| `Start station` / `End station` | 字符串 | 缺失值、拼写不一致 |
| `Bike number` | 字符串 | 有脏数据（不是数字的编号） |
| `Member type` | 分类 | 只有两类 |

**真实数据的典型问题：**
- **缺失值** —— 某些字段为空
- **离群值** —— 时长几秒（误触）或几十小时（忘还）
- **类型不对** —— 日期是字符串，编号混了非数字
- **量纲不一** —— 时长是秒，温度是摄氏度，量级差很多

**这一步通常占整个项目 60-80% 的时间。**

---

## 三、特征工程：从时间戳里榨出信息

**原始只有一个时间戳，但可以拆出很多有意义的特征：**

```python
df['Start date'] = pd.to_datetime(df['Start date'])
df['hour']       = df['Start date'].dt.hour        # 几点
df['dayofweek']  = df['Start date'].dt.dayofweek   # 周几
df['month']      = df['Start date'].dt.month       # 月份
df['is_weekend'] = df['dayofweek'] >= 5            # 是否周末
df['is_rush']    = df['hour'].isin([7,8,9,17,18,19])  # 是否通勤高峰
```

**为什么这样做？**

模型看不懂"2022-12-25 08:30"这个字符串，但能理解「**周六早上 8 点**」这个模式。

**这里的洞察是：**

> **通勤时段（工作日早高峰）的骑行目的，和周末下午完全不同。**
> 前者是"赶时间"，后者是"休闲" —— 时长分布必然不同。

**特征工程的价值就在于：把领域知识编码进数据。**

### 分类变量要编码

```python
pd.get_dummies(df, columns=['Member type'])   # One-hot 编码
```

`Member type`（会员/临时）是字符串，要变成 `[0,1]` 或两个哑变量列。

## 四、清洗：处理离群值

```python
# 去掉明显不合理的
df = df[(df['Duration'] > 60) & (df['Duration'] < 3*3600)]
#                  ↑ 至少 1 分钟        ↑ 最多 3 小时
```

**为什么这步重要？**

线性回归用**最小二乘**，而最小二乘对离群值**极度敏感** ——
一个 24 小时的记录能把回归线整个拉偏。

**处理离群值的几种思路：**

| 方法 | 做法 | 适用 |
|:---|:---|:---|
| **直接删** | 超出合理范围就丢 | 明显是记录错误的 |
| **截断（Winsorize）** | 超出范围就设成边界值 | 保留样本但削弱影响 |
| **对数变换** | `log(duration)` | 长尾分布 |
| **稳健回归** | 用 Huber loss | 不想手动处理 |

## 五、建模

**作业主要用线性回归做"可解释性"分析：**

```python
from sklearn.linear_model import LinearRegression
model.fit(X_train, y_train)
print(dict(zip(feature_names, model.coef_)))
```

**为什么用线性回归而不是更复杂的模型？**

> **因为这个作业的目标是「解释」而不是「预测」。**
>
> 线性回归的系数**直接告诉你"这个因素每增加 1，时长变化多少"** ——
> 这是随机森林、神经网络给不了的。

**这就是「可解释性 vs 预测能力」的权衡。**

---

## 六、线性回归的假设（面试常考）

| 假设 | 含义 | 违反了怎么办 |
|:---|:---|:---|
| **线性** | 特征和目标是线性关系 | 加多项式特征 |
| **独立** | 样本之间独立 | 时间序列要用别的模型 |
| **同方差** | 残差方差恒定 | 加权最小二乘 |
| **正态残差** | 残差服从正态 | 影响置信区间，不影响点估计 |
| **无多重共线性** | 特征之间不高度相关 | 删特征 / 岭回归 |

**多重共线性在时间特征里特别常见** —— `hour` 和 `is_rush` 就是强相关，
同时放进去会让系数变得不可信。

**建议的改进方向：**
- **对数变换** —— 时长是长尾分布，取 log 后线性假设更成立
- **加交互特征** —— `hour × is_weekend`，捕捉"周末早高峰"这种组合模式
- **正则化** —— 岭回归（L2）处理共线性
- **外部数据** —— 加天气数据（温度、降水），那是最强的预测因子
