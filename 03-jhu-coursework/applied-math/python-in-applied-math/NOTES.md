### 004 / 007 · 最小代价路径 ⭐

**问题：** 在给定地形（高度场）上，从起点到终点找**总代价最小**的路径。

```python
# H1.npy ~ H5.npy 是水平代价，V1.npy ~ V5.npy 是垂直代价
# 每个格子有「横向通过」和「纵向通过」两种代价
```

**这是一个经典的动态规划问题：**

```
cost[i][j] = min(cost[i-1][j] + V[i-1][j],     # 从上面来
                 cost[i][j-1] + H[i][j-1])      # 从左边来
```

**为什么用 DP 而不是暴力搜索？**

| 方法 | 复杂度 | 说明 |
|:---|:---|:---|
| 暴力枚举 | **指数级** | 路径数量爆炸 |
| **动态规划** | **O(mn)** | 每个格子只算一次 |

**核心洞察：最优路径的子路径也是最优的**（最优子结构）——
所以可以从起点一路递推到终点。

### 005 · 布朗运动

**布朗运动：粒子受随机碰撞的连续运动。**

**数学定义：**
```
B(0) = 0
B(t) - B(s) ~ N(0, t-s)          # 增量服从正态分布
不同区间的增量互相独立
```

**离散模拟（蒙特卡洛）：**

```python
dt = 0.01
steps = int(T / dt)
increments = np.random.normal(0, np.sqrt(dt), steps)   # ← 注意 sqrt(dt)
path = np.cumsum(increments)                            # 累积和
```

> ⚠️ **关键细节：标准差是 `sqrt(dt)` 不是 `dt`。**
> 这是布朗运动的标度性质 —— 方差和时间成正比，所以标准差和 √时间 成正比。
> 搞错这一步，模拟出来的路径就不对了。

**为什么要模拟？** 因为布朗运动的很多性质（首达时间、极值分布）
**没有解析解**，只能靠蒙特卡洛。

### 006 · 订单簿模拟 ⭐

**这是最"工程"的一个作业** —— 模拟一个真实的交易订单簿。

**数据结构：**

```
买盘（Bid）  价格从高到低
卖盘（Ask）  价格从低到高
             ↑ 中间是最优买卖价，差价叫 spread
```

**需要维护的操作：**
- **限价单（Limit Order）** —— 挂单进队列
- **市价单（Market Order）** —— 立即成交
- **撤销（Cancel）** —— 从队列移除

**为什么难？**

> **订单簿对数据结构的要求很苛刻** —— 每秒钟可能有几万次更新，
> 既要快速找到最优价，又要快速插入/删除。
>
> 实际交易系统会用**跳表、红黑树、或者数组+位图**等专门结构。

**这是"离散事件模拟"** —— 不按固定时间步推进，而是**按事件发生顺序**推进。

### 008 · 随机微分方程

**从布朗运动升级：**

```
dX = μ·X·dt + σ·X·dB
     ↑          ↑
   确定性漂移   随机扰动
```

**这是几何布朗运动** —— 金融里描述股价的经典模型（Black-Scholes 的基础）。

**数值解法（Euler-Maruyama）：**

```python
X = np.zeros(steps)
X[0] = X0
for t in range(steps-1):
    dW = np.random.normal(0, np.sqrt(dt))
    X[t+1] = X[t] + mu*X[t]*dt + sigma*X[t]*dW
    #              ↑ 漂移项         ↑ 扩散项
```

**用到真实数据** —— `SP500Daily.csv` / `SP500Weekly.csv`（标普 500 指数）。

**关键实验：对比日线和周线数据估计出的 μ 和 σ。**

> 理论上这两者应该一致（都是同一个过程的估计），
> 但实际数据往往不一致 —— 这叫「**时间尺度不变性被破坏**」，
> 是金融建模的核心难题之一。

### 002 · 基因组字符串 / 003 · Nim

