> **这是我本科机械阶段的纯机械项目** —— 几乎没有代码，重点在几何设计。

---

## 一、问题：怎么用旋转电机做出"走路"

**难点：** 电机只能**旋转**，但走路需要腿做**复杂的往复运动**。

**两条路线：**

| 路线 | 做法 | 特点 |
|:---|:---|:---|
| **机电**（如波士顿动力） | 每个关节一个电机 + 传感器 + 控制算法 | 灵活，但复杂、贵、要写控制 |
| **机构**（本项目） | 用**连杆**把单一旋转运动直接转成行走轨迹 | **简单、便宜、无需控制** |

**连杆路线的核心思想：**

> **把"控制问题"转化成"几何设计问题"。**
> 不用写一行控制代码，靠连杆的几何关系直接生成步态。

## 二、四杆机构：机械设计的 ABC

**最基础的连杆机构，四个杆、四个铰链：**

```
     A ●━━━━━━━━● B
       │        │
       │        │        ← 四杆机构（曲柄摇杆）
       │        │
     D ●━━━━━━━━● C
```

**自由度分析（Gruebler 公式）：**

```
F = 3(n-1) - 2j
    n = 4（四个构件：连架杆×2 + 连杆 + 机架）
    j = 4（四个低副铰链）

F = 3×(4-1) - 2×4 = 9 - 8 = 1
```

**结果 1 个自由度** —— 输入一个电机转角，整个机构的位置就完全确定。
**这就是"把控制问题变成几何问题"的数学表达。**

## 三、`design.m` 在算什么

代码只有 82 行，但内容是**四杆机构的闭环位置分析**：

```matlab
L0=2.5;  L1=0.5;  L2=2;  L3=1.2;   % 四根杆的长度
theta2 = 0:2:360;                   % 输入杆转一整圈

for i = 1:length(theta2)
    % ① 用余弦定理求对角线长度
    AC(i) = sqrt(L0^2 + L1^2 - 2*L0*L1*cosd(theta2(i)));

    % ② 用余弦定理求各角
    beta(i)  = acosd((L0^2 + AC^2 - L1^2) / (2*L0*AC));
    psi(i)   = acosd((L2^2 + AC^2 - L3^2) / (2*L2*AC));
    lamda(i) = acosd((L3^2 + AC^2 - L2^2) / (2*L3*AC));

    % ③ 求输出角
    theta3(i) = psi(i) - beta(i);
    theta4(i) = 180 - lamda(i) - beta(i);
```

**核心工具就是余弦定理：**

```
c² = a² + b² - 2ab·cos(C)
```

**反复用在三角形的三条边上。** 这就是**解析法做机构综合** ——
不用迭代，直接算出每个输入角对应的完整位形。

**`if theta2(i) > 180` 那段是在处理"分支切换"** ——
同一个输入角可能对应两种装配方式（如四杆机构的"开式"和"交叉"），
需要分段处理。

## 四、从四杆到腿部机构

**把四杆机构稍作变形，让连杆上的某一点走出一条"近似直线"或"椭圆"轨迹，
那就是一条腿的步态。**

**经典的腿部机构：**

| 机构 | 发明者 | 特点 |
|:---|:---|:---|
| **Klann linkage** | Joe Klann | 模拟蜘蛛腿，6 杆 |
| **Jansen linkage** | Theo Jansen | 风靡的"沙滩兽"用的，11 杆 |
| **Chebyshev** | 切比雪夫 | 数学上优雅的近似直线机构 |

**共同点：用一个旋转电机，通过连杆几何直接生成"抬腿-前摆-落地-后蹬"的循环。**

**本项目的目录里有 `DOM Walking Robo Final Presentation.pptx`（16M）** ——
里面应该有具体的机构图和运动分析。

## 五、为什么这算机器人的"前身"

**这个项目和后来的 UR5 / Delta 是同一套数学：**

| 概念 | 四杆机构 | 机械臂 |
|:---|:---|:---|
| 描述位形 | 各杆的角度 | 各关节的角度 |
| 约束 | 闭环（首尾相接） | 开链（一串到底） |
| 求解 | **闭环位置分析** | 正/逆运动学 |
| 工具 | **余弦定理** | 齐次变换矩阵 |
| 自由度 | Gruebler 公式 | Gruebler 公式 |

**同一个问题：给定输入，求输出位置。** 只是从二维四杆变成了三维多关节。

> 💡 这也是我在 `LEARNING-PATH.md` 里说的：**机械背景是资产**。
> 你在本科做的连杆分析，和研究生课里学的机器人运动学是**同源的**。

**建议的改进方向：**
- **参数扫描** —— 用 MATLAB 遍历杆长组合，找最优步态
- **加足端轨迹** —— 现在的分析停在连杆点，再往下算"脚"的轨迹
- **逆问题** —— 给定想要的步态轨迹，反推杆长（机构综合）
- **加动力学** —— 现在是纯运动学，没考虑惯量和受力
